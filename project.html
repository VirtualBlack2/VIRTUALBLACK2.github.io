My Computer Science Projects

Here are some projects I have worked on.

ZERO HOUR

ZERO HOUR is a World War II game that I created in Roblox Studio using Lua. It includes weapons, player statistics, and different game modes.

Lightnata

Lightnata is a mobile app that helps people report and view electricity outages in The Gambia. I used Flutter and Firebase to build it.

Contract Tracker

During my internship at Steptoe LLP in Washington, D.C., I created a Microsoft Copilot Studio agent that allowed users to search and filter a repository of software licenses and contracts. The agent made it easier to find contract details, vendors, and upcoming expiration dates through a conversational search. It also had the ability to send alerts and reminders for upcoming contracts that expire soon through a directory I built for the firm.

RECOIL Discord Bot

RECOIL is a Discord bot for my Roblox community. It includes moderation commands, support tickets, announcements, and player statistics.

COMP335 Final Group Project Idea

BSU Campus Resource Finder

For the final group project, I would like to create a BSU Campus Resource Finder. Students could search for services such as tutoring, Wi-Fi support, counseling, accommodations, student employment, and campus safety. The website would show the correct campus office, what it helps with, its location, and its contact information. The goal is to make campus resources easier for students to find.
